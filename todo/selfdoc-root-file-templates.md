# Adopt selfdoc root file templates

selfdoc now supports generating root-level files (CLAUDE.md, README.md) from
templates in `docs/` that can contain `:::directive` blocks. Templates are
underscore-prefixed (`docs/_CLAUDE.md`, `docs/_README.md`), and `selfdoc gen`
resolves directives and writes the output to the project root with a
read-only auto-generated header.

## What could use directives

### CLAUDE.md
- **Project structure** (lines 7-29): replace the manual tree with `:::list-tree`
- **Key conventions / exit codes** (line 55): replace the inline table with `:::table-schema exitcodes.go` or `:::ref exitcodes.go`
- **CLI usage examples** (lines 83-121): could use `:::code-help saferm` for the help output

### README.md
- **Commands section** (lines 48-111): replace manual flag docs with `:::code-help` per subcommand
- **Exit codes table** (lines 182-192): extract from `exitcodes.go` with `:::table-schema`
- **Install table** (lines 39-44): static, but other sections benefit from extraction

## Migration steps

1. Create `docs/_CLAUDE.md` -- copy current CLAUDE.md content, replace manual sections with directives
2. Create `docs/_README.md` -- copy current README.md content, replace manual sections with directives
3. Add `"root_files": ["docs/_CLAUDE.md", "docs/_README.md"]` to `selfdoc.json`
4. Add the auto-generated header to existing CLAUDE.md and README.md (first line: `<!-- Auto-generated by selfdoc from docs/_CLAUDE.md -- do not edit -->`)
5. Run `selfdoc gen` to verify output matches expectations
6. Commit the templates and updated root files
